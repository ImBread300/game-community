## Запуск и проверка

Откройте `index.html` в браузере или через Live Server. Для загрузки Bootstrap с CDN нужен интернет. Установка зависимостей и сборка не требуются.

1. Проверить навигацию и переходы между страницами.
2. Проверить карточки, кнопки, значки и сообщения.
3. Открыть и закрыть модальное окно.
4. Проверить заполнение и сброс формы заявки.
5. Проверить раскрытие accordion в каталоге.
6. Проверить адаптивность на ширинах 375, 768, 1024 и 1440 px.
