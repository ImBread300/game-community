# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Game Community — учебный сайт сообществ любителей видеоигр: CS2, Stardew Valley, OneShot и Barotrauma. Оформление выполнено в палитре OneShot.

## Практическая работа №9

Создана главная страница на Bootstrap-сетке.

Реализовано:

- Bootstrap CSS и JS Bundle через CDN, собственный `css/custom.css`;
- шапка и адаптивная Bootstrap-навигация;
- hero-блок, преимущества и сетка игр `col-12 col-md-6 col-lg-4`;
- простые страницы игр с описаниями, обложками и иконками;
- переходы между страницами, подвал и ссылка «Наверх».

## Используемые технологии

- HTML5;
- Bootstrap 5.3.3;
- CSS3;
- Git и GitHub.
