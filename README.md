# Контрольная работа №3

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Game Community — учебный сайт сообществ любителей Counter-Strike 2, Stardew Valley, OneShot и других игровых сообществ.

## Ссылка на опубликованный проект

GitHub Pages: [открыть сайт](https://imbread300.github.io/game-community/).

## Дополнительные доработки

1) **Рекомендации:** карусель шести игр на главной странице с автоматической сменой, стрелками, индикаторами и кнопкой паузы.
2) **Избранное:** игры и материалы можно отметить кнопкой со звездой. Избранные карточки поднимаются наверх, для материалов доступен отдельный фильтр. Выбор сохраняется в localStorage браузера и используется на разных страницах сайта.
3) **Тёмная и светлая темы:** переключатель в верхнем меню плавно меняет оформление. Выбранная тема сохраняется.
4) **Руководства:** для каждой из шести игр добавлено краткое руководство с оригинальным изображением. Текст открывается в модальном окне с оглавлением и переходами по разделам.

5) **Профиль:** общие данные пользователя и просмотр всех или избранных игр. Создание профиля не привязано к игре; данные хранятся в браузере.
6) **Общая разметка:** меню и подвал формируются из одного файла `js/layout.js`; пути и активные пункты определяются автоматически.

## Подключение Bootstrap

Используются `vendor/bootstrap/css/bootstrap.min.css` и `vendor/bootstrap/js/bootstrap.bundle.min.js`. Собственный `css/style.css` подключается после Bootstrap. В `vendor/bootstrap/` сохранена лицензия библиотеки.

## Используемые технологии

HTML5, Bootstrap 5.3.3 (локально), CSS3, JavaScript, Git и GitHub. Собственные стили дополняют компоненты и сетку Bootstrap.

## Запуск и проверка

Откройте `index.html` в браузере или через Live Server. Bootstrap, стили и изображения находятся в проекте. Для просмотра страниц интернет не нужен; внешние видео открываются на YouTube. Установка зависимостей и сборка не требуются.

1. Проверить навигацию и переходы между страницами.
2. Проверить карточки, кнопки, значки и сообщения.
3. Открыть и закрыть модальное окно.
4. Проверить создание и редактирование профиля, сохранение избранного.
5. Проверить раскрытие accordion в каталоге.
6. Проверить адаптивность на ширинах 360, 375, 768, 1024 и 1440 px.
