## Подключение Bootstrap

Используются `vendor/bootstrap/css/bootstrap.min.css` и `vendor/bootstrap/js/bootstrap.bundle.min.js`. Собственный `css/style.css` подключается после Bootstrap. В `vendor/bootstrap/` сохранена лицензия библиотеки.

## Самостоятельные доработки

Шесть игровых центров, оформление в палитре OneShot, ленты материалов с фильтрами, выбор игры в заявке по ссылке, кнопка «Наверх» и реакции Нико на ошибки, успешное заполнение, выбор сообщества и сброс формы.

## Структура проекта

```text
game-community/
├── index.html             # Главная
├── catalog.html           # Каталог сообществ
├── product.html           # Подробная страница CS2
├── order.html             # Заявка на участие
├── games/                 # Страницы 6 игр
├── css/style.css          # Общая палитра и стили
├── js/main.js             # Фильтры материалов, формы и выбор игры
├── images/                # Локальные обложки, иконки, иллюстрации и sources.json
├── vendor/bootstrap/      # Локальные CSS, JS, карты исходников и лицензия
├── .gitignore
└── README.md
```

## Запуск и проверка

Откройте `index.html` в браузере или через Live Server. Bootstrap, стили и изображения находятся в проекте. Для просмотра страниц интернет не нужен; внешние видео открываются на YouTube. Установка зависимостей и сборка не требуются.

1. Проверить навигацию и переходы между страницами.
2. Проверить карточки, кнопки, значки и сообщения.
3. Открыть и закрыть модальное окно.
4. Проверить заполнение и сброс формы заявки.
5. Проверить раскрытие accordion в каталоге.
6. Проверить адаптивность на ширинах 360, 375, 768, 1024 и 1440 px.
